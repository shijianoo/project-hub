# ProjectHub 用户使用手册

## 1. 登录与首页

使用管理员创建的账号登录。登录页面需要填写用户名、密码和图形验证码。系统使用访问令牌调用接口，并在访问令牌到期时使用刷新令牌自动续期；刷新失败后会要求重新登录。

首页展示今日、本周、本月工时、活跃项目数量、项目投入分布和最近工时记录。顶部通知铃铛会显示未读提醒。

## 2. 项目团队、权限与专业岗位

系统权限、项目权限和专业岗位是三个不同维度。用户在某个项目中是负责人，不代表在其他项目中也拥有负责人权限；“硬件工程师”等专业岗位只用于描述该项目内的分工，不会自动提升管理权限。

| 项目权限 | 主要权限 |
| --- | --- |
| 项目负责人 | 管理项目、成员、工时任务、全部资产和目录权限 |
| 项目管理员 | 管理项目内容、全部资产和目录权限，但不能违规转移负责人 |
| 项目参与者 | 填报本人工时、上传资产、维护本人资产和有编辑权的目录 |
| 只读成员 | 浏览项目和获准访问的资产，不能填报或修改 |

项目编辑页为每位成员提供可多选的专业岗位，覆盖项目管理、系统、结构、机械、电气、硬件、固件、软件、前端、后端、移动端、算法、数据、测试、质量、工艺、工业设计、技术文档、部署运维和技术评审等专业。无法归类时可选择“其他岗位”并填写自定义名称。

同一成员可以同时是“项目负责人 + 软件工程师”，也可以同时承担“硬件工程师 + 固件工程师”。“项目职责”用于进一步记录工作边界和主要交付物。项目详情和资产目录授权页都会展示这些专业岗位，便于跨专业团队快速识别成员分工。

进入“项目中心”可以查看项目详情、团队专业构成和成员职责。项目卡片上的“资产”按钮可直接进入对应项目资产中心。

## 3. 工时填报

进入“工时中心 → 我的工时”：

1. 选择周次。
2. 在日期、项目和任务交叉位置填写投入时长及工作内容。
3. 可以批量保存、复制已有记录，也可以使用计时器开始、暂停和结束工作。
4. 周内工时完成后执行周确认；被管理员锁定后不可继续修改。

系统会根据“工时规则”检查最小填报粒度、每日最大工时、未来日期、周末、内容必填和可修改天数。

## 4. 项目资产中心

### 4.1 目录和工种

左侧目录树的第一层是工种分类，例如结构设计、建模、硬件、固件、软件、说明文档和手册资料。分类下可以创建任意层级业务目录。

在系统中创建、重命名、移动或删除空目录时，服务器资产根目录中的物理目录会同步变化。物理目录名称包含稳定标识，便于发生人工移动时定位数据库记录。

### 4.2 上传资产

点击“上传资产”，或把文件直接拖到资产中心页面：

1. 选择工种分类和目标业务目录。
2. 一次可加入最多 100 个文件。
3. 系统会根据扩展名推断资产类型，可逐项修正名称和类型。
4. 最多同时上传 3 个文件，每项显示独立进度和失败原因。
5. 上传成功后，每个文件成为一项独立资产并产生 v1 版本。

### 4.3 版本历史

点击资产卡片进入详情抽屉：

- 查看资产说明、当前文件和完整版本历史。
- 下载任意历史版本。
- 复制 SHA-256 完整性摘要。
- 有编辑权限时上传新版本，并填写变更说明。

上传新版本只替换可见工作区中的当前文件，不会覆盖历史版本。

### 4.4 在线预览

系统支持：

- 图片和 SVG。
- PDF。
- Markdown、文本、JSON、XML、YAML 和常见源代码。
- Excel、CSV 表格，在线最多显示前 500 行。
- 音频和视频。
- GLB、GLTF、OBJ、STL 三维模型，可旋转、缩放和平移。

DWG、STEP、IGES、Office 工程文件、EDA 工程和固件产物会给出对应专业软件建议，并保留下载功能。

### 4.5 目录权限

项目负责人、项目管理员和系统管理员拥有全部目录权限。其他成员可以配置：

- 不可访问：目录及其未单独授权的下级目录不可见。
- 只读：可以浏览、预览、下载和打包。
- 可编辑：可以创建子目录并维护该目录中的资产。
- 继承上级：使用距离目标最近的父目录显式权限。

项目参与者始终可以维护本人创建的资产；获得目录编辑权限后，也可以维护该目录中的内容。只读成员不能被授予编辑权限。

### 4.6 回收站和打包

删除资产会把工作区当前文件移除，但不可变历史版本仍保留。进入“回收站”可恢复有权维护的资产。

“打包下载”可以按当前分类或目录生成 ZIP，并选择仅当前版本或全部历史版本。受限目录不会进入压缩包。

## 5. 通知中心

站内通知包括：

- 日工时不足提醒。
- 周工时未确认提醒。
- 加入项目、移出项目，以及项目权限、专业岗位或职责变化。
- 新增项目资产和上传新版本。
- 资产目录权限变化。

SMTP 配置完整时，通知会同时进入邮件发件箱。SMTP 未配置、不可用或用户没有邮箱时，站内通知仍正常生成。

## 6. 报表

进入“工时报表 → 报表设计与导出”：

- 选择工时明细、项目汇总或人员汇总数据源。
- 配置日期、项目、人员和关键词筛选。
- 自定义列标题、显示状态、宽度和排序。
- 保存为个人或公共报表模板。
- 预览后导出 Excel 或 CSV。

## 7. 管理功能

系统管理员可以维护用户账号、重置密码、配置工时规则、查看操作日志并手动触发工时提醒。

项目管理角色可以在资产中心打开“物理存储健康检查”：

- 快速检查工作文件、版本文件和孤立文件。
- 执行深度 SHA-256 检查。
- 从不可变版本库重建当前工作区。
- 孤立文件只会移动到 `.recovery` 恢复区，不会直接删除。
